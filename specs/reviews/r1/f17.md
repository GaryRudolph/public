Finding: r1.f17
Claim: fixed
Change: `agents/Makefile` takes a `CLAUDE_CONFIG_DIRS` list (space-separated absolute paths, default `$(HOME)/.claude`, normally set in `agents/local.mk`; relative or empty lists are refused) in place of the two single-dir defaults `CLAUDE_HOME` and `CLAUDE_DATA_HOME` and the `CLAUDE_SKILLS_HOME` and `CLAUDE_COMMANDS_HOME` derived from the first. `agents/lib/blocks.sh`, `extensions.sh`, `allowlists.sh` and `local-marketplace.sh` loop over it, so each dir keeps its own `CLAUDE.md` block, skills and commands links, `settings.json` with its own sidecars and `.history/`, and marketplace (run with `CLAUDE_CONFIG_DIR` set to that dir). `make status` starts with a new `status-claude-dirs` (`agents/lib/claude-dirs.sh`) that lists the managed dirs and names any other `~/.claude*` directory as `? not managed`. `agents/runbook.md` and `agents/README.md` explain the list and the routing it has to match (`dotfiles/fish/conf.d/65-aliases.apps.fish`, `macos-launchers/apps/claude.applescript`). The WSL Windows-side copies stay single, and the change is in this repo only: the Agerpoint bok's copy of `agents/lib/` still needs the port.
Evidence: `agents/tests/test-claude-dirs.sh` (`make -C agents test-claude-dirs`, part of `test`) runs the real Makefile in a sandbox `$HOME` with two dirs: install writes the block, skills, allowlist and sidecar into both and creates no `~/.claude`; `install-local-marketplace` calls a stub `claude` once per dir with that dir as `CLAUDE_CONFIG_DIR`; uninstall returns the home to its pre-install snapshot; `make status` names an unlisted `~/.claude-x`, skips `~/.claude.json`, lists a repeated dir once, and the default list names `~/.claude-a` as unmanaged; a relative path is refused, and so is a `CLAUDE_HOME` or the other retired variables set on the command line or in `local.mk` (they would otherwise be silently ignored). Breaking `is_listed` or making `all_targets` read only the first dir makes it fail. The existing blocks, extensions, hooks, allowlists and roundtrip tests now pass `CLAUDE_CONFIG_DIRS`. `make -C agents validate test` passes.
