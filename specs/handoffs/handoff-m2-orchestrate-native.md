## Gotchas

- **Two gate hooks on the Mac.** The lolay CLI now has the org-synced `orch-spike` besides `--plugin-dir plugins/personal`; both hooks match `*:plan-segment` and run on every launch. They agree today; after m2.s2 changes `personal`'s, the old `orch-spike` copy may deny what the new one allows, so rebuild and re-sync `orch-spike` (or remove it from the org) before dogfooding.
- **Paste shapes differ:** the Mac CLI wraps a bracketed paste in `<pasted_content id="…">`; the web doesn't.
- **The web harness blocks `sleep N; cmd` chains** in the parent's Bash.
- `ANTHROPIC_DEFAULT_SONNET_MODEL` no longer remaps the workflow's `sonnet` workers; cheap stand-ins need another route.
- A workstation fixture nested inside this repo looks like part of it to git; use `GIT_CEILING_DIRECTORIES` (as `.scratch/spike/w3/run.sh` can) or a folder outside the repo.
- Merging waits on nothing from m1 now (criterion 6 held); merge with a squash and an explicit title and description.
- Remove the scratch repo's branches and the org's `orch-spike-lab` source after m2.s9 (Gary's call; m2.s10 asks).
