# How-tos

Step-by-step guides for people who aren't engineers but can drive an agent. Each one opens with a prompt you paste into Claude Code, which reads the guide and does the setup for you. The rest of the guide explains what it's doing and why.

| How-to | What it does |
|---|---|
| [Mac: two Claude accounts](mac-two-claude-accounts.md) | Run a primary and a secondary Claude account side by side: the Claude app, its Code tab, and the `claude` terminal command. |
